🧮 Simple Calculator

A modern, simple, and user-friendly calculator designed for everyday mathematical calculations. Built using HTML, CSS, and JavaScript, this calculator provides a clean interface and smooth user experience across all devices.

✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage Calculation
- 🧹 Clear (AC) Button
- ⌫ Delete (DEL) Button
- ⌨️ Keyboard Support
- 📱 Fully Responsive Design
- ⚡ Fast and Lightweight
- 🎨 Clean and Modern User Interface

🛠️ Built With

- HTML5 – Structure
- CSS3 – Styling and Responsive Layout
- JavaScript – Calculator Functionality

📂 Project Structure

Simple-Calculator/
│
├── index.html      # Main HTML file
├── style.css       # Calculator styling
├── script.js       # Calculator functionality
└── README.md       # Project documentation

🚀 Getting Started

Follow these simple steps to run the calculator:

1. Clone this repository:
   
   git clone YOUR_REPOSITORY_LINK

2. Open the project folder.

3. Open "index.html" in your web browser.

4. Start calculating!

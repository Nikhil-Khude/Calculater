# 🧮 Simple Calculator

A clean and easy-to-use calculator for daily calculations.  
It is built with **HTML, CSS, and JavaScript**.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculation
- 🧹 Clear button
- ⌫ Delete button
- ⌨️ Keyboard support
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
